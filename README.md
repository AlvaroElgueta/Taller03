# Taller 03 - Spooky Season

## Descripcion del proyecto

Programa desarrollado para el Taller 03 de Programacion Orientada a Objetos.

El sistema simula distintos minijuegos de Halloween en los que cada jugador
puede transformarse en monstruos con atributos y habilidades diferentes.
Tambien permite consultar el catalogo de monstruos, revisar el historial de la
sesion, mostrar el ranking de jugadores y guardar sus puntajes maximos.

## Instrucciones de ejecucion

1. Clonar el repositorio desde una terminal:

```bash
git clone https://github.com/AlvaroElgueta/Taller03.git
```

2. Abrir Eclipse y seleccionar `File > Import`.
3. Seleccionar `General > Existing Projects into Workspace`.
4. Elegir la carpeta clonada `Taller03`.
5. Ejecutar `src/Taller03/Main.java` como `Java Application`.
